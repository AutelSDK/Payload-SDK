## What is the Autel Payload SDK
Autel Robotics provides the Payload SDK (PSDK) development toolkit, along with development accessories like standard gimbals, adapter rings, and coaxial cables, to support developers in creating payload devices that can be mounted on Autel Robotics drones. This enables developers to leverage the drone’s resources, such as power, communication links, and status information. Developers can design payload devices, such as automatic inspection systems, infrared cameras, loudspeakers, and searchlights, to meet various industry-specific needs based on the functional interfaces provided by PSDK. Furthermore, they can combine these devices with MSDK and Cloud API to create complete application solutions for real-world scenarios.
